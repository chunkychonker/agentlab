## 1. Pipeline stages

Opportunities move through five stages in order: `Prospecting` ->
`Qualified` -> `Proposal` -> `Negotiation` -> `Closed Won` (or
`Closed Lost` from any stage). An opportunity cannot skip a stage in
reporting even if the deal itself moved fast in reality — the CRM stage
history must show each stage it passed through.

## 2. Opportunity weighting

Pipeline value is reported both unweighted (full deal value, any open stage)
and weighted (deal value * stage-close-probability). Default stage
probabilities: Prospecting 10%, Qualified 25%, Proposal 50%,
Negotiation 75%. `Closed Won` counts as 100% and moves out of "pipeline"
into "bookings."

## 3. Quota attainment

Quota attainment is measured on **Closed Won bookings dated in the quarter**,
not on pipeline generated in the quarter. A rep who closes a deal that was
prospected two quarters ago gets 100% credit for it in the quarter it
closes, not the quarter it was created.
